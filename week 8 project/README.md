# Golden Threads - Premium Handcrafted Bracelets

A beautiful, responsive multipage website for a bracelet business showcasing products, company information, and customer contact features.



## 📋 Project Overview

This project is a complete multipage website for **Golden Threads**, a premium bracelet business. The website features:

- **4 Main Pages**: Home, About, Products, and Contact
- **Fully Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Elements**: Mobile menu, form validation, scroll animations, and smooth transitions
- **Modern UI/UX**: Clean, elegant design with a professional color scheme
- **Semantic HTML5**: Properly structured and accessible markup
- **Production-Ready**: Organized codebase following best practices

## 🎨 Features

### Pages

1. **Home (index.html)**
   - Hero section with call-to-action
   - Featured products showcase
   - About preview section
   - Smooth scroll animations

2. **About (about.html)**
   - Company mission and values
   - Craftsmanship information
   - Story and background

3. **Products (products.html)**
   - Complete product catalog (9 products)
   - Product cards with hover effects
   - Custom orders section
   - Scroll-triggered animations

4. **Contact (contact.html)**
   - Contact form with validation
   - Business information
   - FAQ section
   - Social media links

### Interactive Features

- **Mobile Navigation**: Hamburger menu for mobile devices
- **Form Validation**: Real-time validation for contact form
- **Scroll Animations**: Products and content animate on scroll
- **Smooth Transitions**: Hover effects and transitions throughout
- **Active Navigation**: Current page highlighting in navigation

### Responsive Design

- Mobile-first approach
- Breakpoints at 768px and 480px
- Flexible grid layouts
- Touch-friendly navigation
- Optimized typography scaling

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid, Flexbox, animations, and custom properties
- **JavaScript (Vanilla)**: No frameworks, pure JavaScript for interactivity
- **Responsive Design**: Mobile-first, adaptive layouts
